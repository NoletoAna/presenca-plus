# Para preencher

Tudo aqui depende de algo que só você sabe ou fez. No Word, esses pontos estão **marcados em amarelo**. Substitua o texto, tire o amarelo e, no fim, clique com o botão direito no sumário e escolha **Atualizar campo**.

## 1. Levantamento (seção 1.3 do relatório)

O PDF exige o levantamento do Passo 0. Basta uma técnica feita de verdade: conversar com alguém de uma escola, olhar dois sistemas parecidos ou usar sua experiência como aluna. Complete os trechos entre colchetes:

> O levantamento foi feito por meio de [técnica], em [mês/ano], com [pessoa e função, ou nome dos sistemas consultados]. Verificou-se que hoje o controle de frequência é feito [como é feito]. As principais dificuldades são [o que você descobriu]. Com base nisso, definiu-se que o sistema deve [o que precisa fazer].

## 2. O que você aprendeu (final das Considerações finais)

Os três primeiros parágrafos já estão escritos, com fatos do projeto. Leia as dificuldades citadas e apague as que não fizerem sentido para você. Falta o parágrafo pessoal:

> Com o projeto, foi possível aprender [conteúdos, de preferência ligando a disciplinas do curso]. A maior dificuldade foi [o que foi difícil para você], superada por meio de [como resolveu].

## 3. Materiais de aula (Referências)

Liste os materiais de aula que você usou, com autor, título, instituição e ano. O PDF diz que eles devem ser referenciados. Modelo:

> SOBRENOME, Nome. **Título do material**. Cuiabá: Instituição, ano. Material de aula da disciplina [nome].

Cite cada um pelo menos uma vez no texto, como (SOBRENOME, ano).

## 4. Link do GitHub (seção 5.1)
